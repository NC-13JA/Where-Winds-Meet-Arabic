# Where Winds Meet — Arabic Localization

مشروع مجتمعي تجريبي لترجمة نصوص لعبة **Where Winds Meet** إلى العربية على Android.

> **الحالة:** بداية المشروع. لم يتم إنشاء ملفات اللعبة المعدّلة أو اختبارها داخل اللعبة بعد.

## الأهداف
- إنشاء قاموس ترجمة عربي واضح وقابل للمراجعة.
- استخدام أدوات تنسيق ملفات اللغة مع الحفاظ على المفاتيح والهاشات وبنية الملف الأصلية.
- بناء ملفات اختبار منفصلة وعدم الكتابة فوق الملفات الأصلية.
- اختبار عرض العربية واتجاه الكتابة (RTL) على الهاتف قبل إصدار أي حزمة.

## الملفات
- `translations/ui.json`: قاموس أولي لمصطلحات الواجهة.
- `docs/TESTING.md`: خطوات النسخ الاحتياطي والاختبار الآمن.
- `tools/validate_translations.py`: التحقق من صيغة قاموس الترجمة.

## تنبيه مهم
وجود نص عربي داخل الملف لا يضمن أن اللعبة ستعرض الحروف متصلة أو بالاتجاه الصحيح. قد يحتاج المحرك أو الخط إلى دعم تشكيل العربية وRTL. لا تستبدل ملفات اللعبة الأصلية قبل الاحتفاظ بنسخة احتياطية قابلة للاستعادة.

## طريقة المساهمة
أضف الترجمات إلى `translations/ui.json` مع إبقاء النص الإنجليزي الأصلي كما هو تمامًا. حافظ على المتغيرات مثل `%s` و`%d` وعلامات التنسيق.
